# Background music

Drop royalty-free tracks here (mp3 / wav / m4a / aac / ogg / flac / opus). Every Short gets one track picked at
random (seeded, so a re-render keeps the same track), starting at a random point, mixed far under the voice
(`music:` in config.yaml: -18 dB in pauses, -26 dB under speech).

Use only music you may use on YouTube (YouTube Audio Library, or tracks whose licence allows it). Anything else
gets a Content ID claim. Check the licence before committing the files to a PUBLIC repo; many free-music licences
allow use in videos but not re-publishing the raw files.

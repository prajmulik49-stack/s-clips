Privacy policy

Last updated: 21 November 2026

crick play is a personal tool used only by its owner to upload Shorts to the owner's own YouTube channel.

What it accesses

  • YouTube upload permission (youtube.upload): to upload videos to the owner's channel.
  • YouTube read-only permission (youtube.readonly): to read the channel's name and confirm the login works.

What it stores and shares

The login token is stored only as an encrypted secret in the owner's GitHub repository and on the owner's computer. No personal data from anyone else is collected, sold or shared with third parties. Google user data is used only to upload the owner's videos, in line with the Google API Services User Data Policy.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
